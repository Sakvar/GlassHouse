# GlassHouse — Agent Instructions

Project-wide guidance for Cursor Composer and Agent.

## Project

GlassHouse is a greenfield repository. Update this file as the stack, architecture, and conventions take shape.

## Working style

- Read existing code before proposing changes.
- Keep diffs focused; avoid unrelated refactors.
- Prefer simple, maintainable solutions over clever abstractions.
- Only add tests when they cover meaningful behavior or when asked.

## Git

- Do not commit unless explicitly requested.
- Do not force-push to `main` or `master`.
- Match existing commit message style when committing.

## When unsure

- Inspect the codebase and relevant docs first.
- Ask a focused question instead of guessing at architecture or requirements.
